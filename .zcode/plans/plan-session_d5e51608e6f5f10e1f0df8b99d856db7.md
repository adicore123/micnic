# תיקון התצוגה שנהרסה + הגדלת הדפסת השחור-לבן

## מה נשבר (ולמה)
בשדרוג ה-A4 העברתי את ה-QR לקנבס 850px (לחדות הדפסה), אבל קנבס מוצג בגודלו הטבעי — **850 פיקסלים שהציפו את כרטיס התצוגה המקדימה** ודרסו את העיצוב (זה מה שרואים בצילום מסך ששלחת). זה באג שלי — מתקן עכשיו.

## התיקון (פשוט ומדויק)
1. **כלל CSS חדש**: ה-QR תמיד ימלא את הקונטיינר שלו (`width/height: 100%`) — הקנבס החד (850px) ייוצג בגודל התצוגה הנכון בלי להציף. זה מחזיר את התצוגה המקדימה לגמרי לצורתה הקודמת הטובה, וגם מתקן את ההצפה בפריסת ה-A4 עצמה.
2. **בדיקה בדפדפן + צילום** שהתצוגה המקדימה חזרה לקדמותה (כרטיס נקי, QR בגודל הנכון).

## הגדלת הדפסת השחור-לבן (כפי שביקשת — "שיהיה יותר גדול הכל")
בפריסת ה-A4 להדפסה מגדיל את כל האלמנטים:
- **קוד ה-QR: 78mm → 90mm** (גדול וקל לסריקה ממרחק)
- לוגו: 44mm → **52mm**
- שם העסק: 34pt → **40pt**
- "מועדון הלקוחות": 19pt → **22pt**
- "סרקו והצטרפו עכשיו": 27pt → **32pt**
- תיבת ההנחה: 22pt → **26pt**
- שורת המשנה: 13pt → **15pt**
- מרווחי המסגרת מתכווצים קלות כדי לפנות מקום לתוכן הגדול

אותן הגדלות חלות גם על פריסת ה-A4 הצבעונית (עקביות).

## אימות
build + בדפדפן: התצוגה המקדימה נקייה (QR נכנס בכרטיס, שום דבר לא מוצף), ה-A4 ב-DOM עם המידות החדשות (90mm QR), צילום לפני/אחרי, ו-commit.

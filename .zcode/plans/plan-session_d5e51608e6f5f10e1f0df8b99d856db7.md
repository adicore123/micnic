# מודול לקוחות נקי — הכול דרך כפתורים ייעודים

## השינוי
במקום הדף הפרוס (טופס הוספה + סטטיסטיקות + חיפוש + טבלה יחד), עמוד המודול יהיה נקי וממוקד:

**בית המודול מציג:**
- שורת סטטיסטיקות (חברים / הצטרפו השבוע / הנחה) — נשארת כי היא קומפקטית
- **שני כפתורי-כרטיס גדולים וייעודיים:**
  - ➕ **הוספת לקוח למועדול** — פותח חלונית עם שני המצבים המוכרים (הלקוח לפניי / שליחת קישור) + מסך ההצלחה עם כפתור הוואטסאפ
  - 📋 **טבלת הלקוחות** (עם מונה) — פותח **מסך מלא ייעודי**: פס כותרת + חיפוש דביק + הטבלה המלאה עם כל הפעולות (הודעה, תפריט, עריכה, הדפסה, מחיקה) + כפתור סגירה בולט

## מה נשמר
כל הפונקציונליות והעיצוב הקיימים — רק הארגון משתנה. שום דבר לא נמחק: אותן פעולות, אותן זרימות, אותן הרשאות. מתאים מובייל (המסכים הפתוחים מלאים ונוחים בטלפון).

## קבצים
`components/AdminDashboard.tsx` בלבד (ארגון מחדש של ה-JSX + שני מצבי פתיחה) · build + בדיקה בדפדפן (שני הכפתורים פותחים נכון, הטבלה וההוספה עובדות מלא) + push.

# 🍕 בונה פיצה אישית תלת-ממדי — עמוד ציבורי `/pizza` באותה שיטה של התפריט

## Context
הלקוח רוצה מודול "פיצה אישית": הפיצה התלת-ממדית מהתפריט + תוספות תלת-ממדיות שבוחרים וגוררים על הפיצה. החקירה גילתה שהפיצה פרוצדורלית לחלוטין: טקסטורות WebP מוטמעות (תמונה 680KB + מפת גבהים + צללית 240-צלעות + בזיליקום) + three.js r160 + גיאומטריית טבעות עם העתקת גבהים + תאורת סטודיו + גרירה לסיבוב. אין עדיין raycasting — נוסיף.

## הארכיטקטורה
1. **`npm i three@0.160 @types/three`** (בדיוק הגרסה בתפריט)
2. **חילוץ הנכסים**: סקריפט חד-פעמי מוציא את ה-JSON של `#pizza-asset` מ-menu.html אל **`public/pizza-asset.json`** (~975KB, קבוע ונשמר ב-cache) — אותן טקסטורות, אותו זהות חזותית מושלמת
3. **`lib/pizza3d/`** (client-only): העתקה מדויקת של טכניקת בניית הפאי מהתפריט — גיאומטריית טבעות + העתקה לפי מפת הגבהים + צללית היקף, CanvasTexture, env-map גרדיאנט, 3 מקורות אור + צללים PCFSoft, לולאת rAF חסכונית (visibility/hidden/drag), גרירה לסיבוב+הטיה (pointer capture), מקלדת, reduced-motion, ופולבק לתמונת still אם WebGL נכשל

## הביניין האישי (`components/PizzaBuilder.tsx` + עמוד `/pizza`)
- **מגש תוספות** (8 תוספות תלת-ממדיות פרוצדורליות באותו סטייל חם): פפרוני, פטריות, זיתים שחורים, טבעות פלפל ירוק, בצל סגול, בזיליקום (**שימוש חוזר בטקסטורת הבזיליקום ובגיאומטריית העלה מהנכס!**), תירס, טבעות גבינה
- **גרירה על הפיצה** (מה שביקשת): pointerdown על תוספת במגש → עותק רפאים עוקב אחרי האצבע (raycast למישור בלתי-נראה) → שחרור → **raycast נגד משטח הפאי** והצמדה מדויקת לגובה הבצק בנקודה (topHeight) — התוספת נכנסת לקבוצת ה-platter ומסתובבת עם הפיצה. הקשה קצרה = הוספה מהירה בנקודה פנויה
- **גרירת תוספת קיימת** על הפיצה להזזה; גרירה החוצה/לפח = הסרה; גרירה על רקע ריק = סיבוב הפיצה (הדפוס הקיים)
- **פס סיכום דביק**: ההרכב החי (פפרוני ×3 · זיתים ×2) + **מחיר כולל מתעדכן בזמן אמת** (בסיס 58₪ + 6–9₪ לתוספת, קבועים במקום אחד) + **כפתור "הזמנה בוואטסאפ"** — שולח לטלפון העסק הודעה מוכנה עם ההרכב המלא (שימוש חוזר ב-lib/whatsapp; אם אין businessPhone בהגדרות — מוסתר)
- **עמוד ציבורי `/pizza`**: RTL, מובייל-first, כותרת עם הלוגו והשם מההגדרות, התאמה מלאה למגע

# מועדון לקוחות "מיקניק" (Micnic) — מערכת ניהול חברי מועדון לפיצרייה

## מה בונים
מערכת Next.js בעברית (RTL) עם שלושה חלקים:
1. **עמוד הצטרפות ציבורי `/`** — טופס פשוט (שם + טלפון) שעובד גם לצוות בדלפק וגם ללקוח שנרשם מהטלפון שלו (דרך ה-QR). אחרי ההרשמה: מסך הצלחה עם אנימציה, הודעת תודה עם אחוז ההנחה, וכרטיס חברות דיגיטלי מעוצב.
2. **פוסטר QR בדלפק `/admin/poster`** — ברקוד QR מעוצב במיוחד (נקודות מעוגלות בצבעי המותג + לוגו העסק במרכז) להצגה על מסך או הורדה/הדפסה לדלפק.
3. **ניהול `/admin`** — דשבורד מוגן סיסמה: הוספת לקוח עם כפתור וואטסאפ גדול ומעוצב (פותח צ'אט מוכן עם ההודעה וההנחה — לחיצה ושליחה), טבלת לקוחות עם חיפוש, סטטיסטיקות, וזיהוי לקוח בקופה לפי טלפון/ברקוד. **הגדרות `/admin/settings`**: העלאת לוגו, שם העסק, מספר העסק, אחוז הנחה, תבנית הודעת הוואטסאפ (עם תצוגה חיה), ושינוי סיסמה.

## טכנולוגיות
- **Next.js 15 (App Router) + TypeScript strict** — קוד נקי, קצר, מקצועי
- **Tailwind CSS** — עיצוב מהיר ועקבי
- **פונט Rubik (Google Fonts)** — פונט העברית הנפוץ והמקצועי ביותר, מעוגל וידידותי — מושלם לפיצרייה
- **jsbarcode** — ברקוד Code128 כ-SVG מסוגנן בצבעי המותג על כרטיס החבר
- **qr-code-styling** — QR מעוצב במיוחד (נקודות מעוגלות, צבעי מותג, לוגו במרכז)
- **zod** — ולידציה נקייה של קלט (טלפון ישראלי, אחוזים)
- **mongodb** — דרייבר רשמי למועד מאוחר
- בלי ספריות כבדות — אנימציות ב-CSS בלבד

## אחסון (לפי בקשתך)
שכבת נתונים אחידה מאחורי interface אחד:
- **עכשיו**: JSON מקומי ב-`data/db.json` (לקוחות + הגדרות) — עובד מיד על המחשב, בלי כלום חיצוני
- **בהמשך**: כשתספק מפתחות Mongo פשוט מוסיפים משתנה סביבה `MONGODB_URI` (ב-Vercel או בקובץ `.env`) — אותו קוד בדיוק עובר ל-MongoDB אוטומטית, בלי שינוי קוד
- מוכן לפריסה ב-Vercel (כולל `.env.example` ו-README בעברית עם הוראות פריסה צעד-אחר-צעד)

## חוויית משתמש (לאנשים לא טכנולוגיים)
- טופס עם **שני שדות בלבד**, ולידציה בזמן הקלדה, הודעות שגיאה בעברית ברורה ("המספר לא נראה תקין...")
- לחיצה אחת → אנימציית הצלחה → כפתור וואטסאפ ענק → וואטסאפ נפתח עם ההודעה המלאה והמספר של הלקוח → **לחיצה על "שלח" וזהו**
- לקוח עצמאי (דרך QR): רואה את ההודעה והכרטיס על המסך שלו, עם כפתור לפתיחת צ'אט עם העסק
- זיהוי בקופה: שורת חיפוש בדשבורד (טלפון/שם) — וגם תמיכה בקורא ברקוד פיזי (סורקים את כרטיס החבר)
- הגדרות בשפה פשוטה, העלאת לוגו בגרירה, תצוגה חיה של הודעת הוואטסאפ לפני שמירה

## עיצוב
פלטת פיצרייה: אדום עגבניות, ירוק בזיליקום, זהב-גבינה, קרם, על רקע פחם כהה-חם יוקרתי. עמוד ההצטרפות — מרשים וכהה עם זוהר חם, כרטיס חברות עם גרדיאנט וברק נע; דשבורד הניהול — בהיר, נקי ונוח לעבודה כל היום. אנימציות עדינות: סימון הצלחה שמצייר את עצמו, כפתורים שמרימים ברחף, כרטיס שנכנס בתלת-ממד קל.

## אבטחה מינימלית הגיונית
`/admin` וכל ה-API של ניהול מוגנים בסיסמה (ברירת מחדל שניתן לשנות בהגדרות), cookie חתום httpOnly. טלפונים מנורמלים ונבדקים נגד כפילויות.

## שלבי הביצוע
1. יצירת פרויקט Next.js + TypeScript + Tailwind, התקנת תלויות
2. שכבת הנתונים (JSON + Mongo adapter) + לוגיקה (טלפון, וואטסאפ, auth)
3. API routes
4. רכיבי ה-UI: כרטיס חבר, ברקוד, QR, כפתור וואטסאפ המעוצב
5. עמודים: הצטרפות, דשבורד, הגדרות, פוסטר
6. ברירות מחדל: לוגו פיצה SVG מקורי, הודעת ברוכים הבאים יפה, הנחה 10%
7. README בעברית + `.env.example` + git init (לקראת פריסה ב-Vercel)
8. אימות: `npm run build` עובר, הרצת dev ובדיקת הזרימה המלאה (הוספה → כרטיס → קישור וואטסאפ → הגדרות)

לאחר הבנייה תוכל להריץ מקומית עם `npm run dev`, וכשתהיה מוכן ל-Vercel + Mongo — פשוט תספק את המפתחות ואני אחבר.

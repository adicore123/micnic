# התאמה מקצועית לדף A4 — פריסת הדפסה אמיתית במילימטרים

## הבעיה
כרגע ההדפסה לוקחת את כרטיס התצוגה המקדימה כמו שהוא (רוחב ~384px) ומציבה אותו בפינת הדף — לא עמוד A4 אמיתי. בנוסף, קוד ה-QR מרונדר בקנבס 280px שיוצא מטושטש בהדפסה (~96 DPI).

## הפתרון

### 1. פריסת A4 ייעודית להדפסה (`components/PosterA4.tsx`)
רכיב חדש שנפרש רק בהדפסה (`hidden print:block`) ומעוצב **במידות פיזיות אמיתיות**:
- עמוד מדויק: **210mm × 297mm** (עם 1mm שמירה נגד גלישה לדף שני)
- מבנה: לוגו 42mm → שם העסק (34pt) → "מועדון הלקוחות" → קו מפריד כפול → **QR ברוחב 78mm ברזולוציית קנבס 850px (~280 DPI — חד בהדפסה)** → קריאה לפעולה → תיבת הנחה → שורת משנה — עם חלוקת מרווחים שממלאת את הגובה בצורה מאוזנת
- **גרסת שחור-לבן**: מסגרת שחורה 0.9mm במרחק 10mm מהקצה (מראה פוסטר קלאסי), כל הטקסט שחור, לוגו בגווני אפור
- **גרסת צבע**: רקע פחם כהה על כל העמוד עם טבעת זהב ללוגו ותיבת הנחה זהובה

### 2. הפרדה בין תצוגה מקדימה להדפסה
- המסך בדפדפן ממשיך להציג את הכרטיס הנוח לצפייה (`print:hidden`)
- בהדפסה מופיעה פריסת ה-A4 (`hidden print:block`) — מה שרואים בתצוגה המקדימה של הדפדפן זה עמוד A4 מלא ומאוזן
- חל על שלושת היעדים: הפוסטר השחור-לבן, הפוסטר הצבעוני, וההורדות (ה-QR עובר לקנבס 850px כך שגם קובץ ה-PNG שיורד יהיה באיכות הדפסה)

### 3. הגדרות עמוד ותיקוני CSS
- `@page { size: A4; margin: 0 }` — הדפדפן יציע A4 אנכי כברירת מחדל, והפוסטר ממלא את כל העמוד (full-bleed)
- איפוס שוליים של body בהדפסה + הצבת יעד ההדפסה בראש הדף בגודל מדויק
- עמוד הדפסת כרטיס החבר מקבל padding משלו (12mm) כדי שהכרטיס ייצא ממורכז ולא צמוד לפינה

### 4. קבצים
- `lib/image.ts` (חדש) — המרת לוגו לגווני אפור (משותף)
- `components/PosterA4.tsx` (חדש) — פריסת ה-A4
- `components/StyledQr.tsx` — פרמטר `displaySize` (קנבס 850px, תצוגה 78mm)
- `components/MonoPoster.tsx`, `components/ShareView.tsx` — הפרדת preview/print
- `app/globals.css` — @page A4 + כללי הדפסה מדויקים
- `components/PrintCardView.tsx` — מרווחי עמוד להדפסת כרטיס

# שדרוג אזור הניהול — סיידבר, עריכה, הדפסת ברקוד ושליחת קישור הצטרפות

## מה הבעיה
הניהול קיים ב-`/admin` אבל הניווט הוא כרטיסיות פשוטות בראש העמוד, אין עריכת לקוחות, אין הדפסת ברקוד, ואין דרך לשלוח ללקוח קישור הצטרפות. מענה מלא על כל הבקשות:

## 1. סיידבר מעוצב (במקום טאבים למעלה)
- **`components/AdminShell.tsx`** (חדש) — סיידבר כהה-יוקרתי בצד ימין (RTL): הלוגו ושם העסק למעלה, ניווט עם אייקונים (לקוחות / שיתוף ופוסטר / הגדרות) עם סימון דף פעיל, וכפתור יציאה למטה.
- **מובייל מקצועי** — במסכים קטנים הסיידבר הופך ל: פס עליון עם כפתור המבורגר → מגירה נפתחת מהצד עם אנימציה ורקע כהה שקוף. כל עמודי הניהול מותאמים לרוחב מסך קטן (סטטיסטיקות וטפסים נערמים, טבלה נגללת).
- קישור קטן "כניסת צוות" בפוטר של עמוד הבית — שלא יהיה עוד בלבול איפה הניהול.

## 2. עריכה ושינוי לקוחות (לערוך ולשנות)
- כפתור עיפרון בכל שורה בטבלה → חלונית עריכה (שם + טלפון) עם ולידציה בעברית.
- API חדש: `PUT /api/customers/[id]` — כולל בדיקה שהטלפון החדש לא שייך ללקוח אחר.
- שכבת הנתונים: `updateCustomer` ו-`findCustomerById` ב-JSON וב-Mongo (אותו interface, מוכן לענן).

## 3. הדפסת ברקוד (להדפיס ברקוד)
- עמוד חדש **`/admin/card/[id]`** — כרטיס חבר בגרסה מותאמת הדפסה: רקע לבן, ברקוד Code128 **גדול וכהה על רקע בהיר** (הכי קריא לסורקים וחסכוני בדיו), שם הלקוח, מספר חבר, לוגו וההנחה.
- כפתור מדפסת בכל שורה בטבלה → העמוד נפתח ו**חלונית ההדפסה נפתחת אוטומטית** — לחיצה אחת ומדפיסים. CSS הדפסה מסתיר את הסיידבר והכפתורים.

## 4. שליחת קישור הצטרפות ללקוח (וואטסאפ)
- עמוד חדש **`/admin/share`** (מאחד את פוסטר ה-QR הקיים):
  - **הזמנה בוואטסאפ**: מזינים מספר טלפון → כפתור הוואטסאפ הירוק הגדול פותח צ'אט עם הלקוח והודעת הזמנה מולאה: "רוצים 10% הנחה? הצטרפו חינם למועדון 👇 [הקישור]" — הלקוח לוחץ, מצטרף מהטלפון שלו ומקבל את ההטבות.
  - **העתקת קישור ההצטרפות** בלחיצה (להדבקה בפוסט/סטורי).
  - **פוסטר ה-QR** המעוצב (כמו היום) עם הורדה להדפסה — לדלפק. `/admin/poster` יפנה אוטומטית לעמוד החדש.
- בהגדרות: שדה חדש **"הודעת הזמנה למועדון"** עם מציין `{link}` ותצוגה חיה — כמו הודעת התודה.

## 5. אימות מלא
build + בדיקה בדפדפן: סיידבר בדסקטופ, המבורגר-מגירה במובייל (viewport 390px), עריכת לקוח, עמוד ההדפסה, שליחת הזמנה, וכל הזרימות הקיימות עדיין עובדות. Commit מסודר בסוף.

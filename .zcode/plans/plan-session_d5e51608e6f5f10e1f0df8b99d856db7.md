# שדרוג נוכחות הלוגו בכל הממשק — ובעיקר בפוסטר ה-QR לדלפק

## 1. פוסטר ה-QR (החשוב ביותר — מה שמוצג בדלפק)
עיצוב מחדש שמציב את מותג העסק במרכז:
- **הלוגו גדל מ-80px ל-112px** (h-28) עם טבעת זהב עבה וצל עמוק — צף בראש הפוסטר
- **שם העסק הופך לכותרת הראשית** בגדול ובזהב (במקום הכותרת הגנרית) — הלוגו והשם מובילים, ומתחת "מועדון הלקוחות"
- **הלוגו במרכז קוד ה-QR גדל** — יחס 0.38 → 0.42 מגודל הקוד (עם רמת תיקון שגיאה H הקוד נשאר סריק לחלוטין, `hideBackgroundDots` מנקה את הרקע מאחורי הלוגו)
- קוד ה-QR עצמו גדל מ-250 ל-270px עם מסגרת קרם רחבה יותר

## 2. שאר הממשק — הלוגו מקבל יותר נוכחות
| מקום | שינוי |
| --- | --- |
| עמוד הבית (hero) | לוגו 80→112px + טבעת זהב עבה + זוהר רקע |
| סיידבר ניהול | לוגו 44→56px, שם העסק מודגדל |
| כרטיס חבר דיגיטלי | לוגו 48→56px עם טבעת זהב |
| כרטיס להדפסה | לוגו 56→64px עם טבעת אדומה עבה |
| מסך כניסת צוות | לוגו 64→80px |
| פוסטר מוקטן בכרטיס ההודעה בהצלחה | מתעדכן אוטומטית |

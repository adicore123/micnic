# 🍕 מועדון הלקוחות — מיקניק פיצה

מערכת ניהול מועדון לקוחות לפיצרייה, בנויה ב-Next.js + TypeScript, בעברית ובעיצוב מותאם אישית.

## מה יש במערכת

| עמוד | כתובת | מי משתמש בו |
| --- | --- | --- |
| הצטרפות למועדון | `/` | לקוחות (דרך ה-QR) וגם הצוות |
| **התפריט הדיגיטלי** | `/menu` | לקוחות — התפריט האיטלקי המלא |
| ניהול לקוחות | `/admin` | הצוות — הוספה, חיפוש, עריכה, הדפסה ושליחת הודעות |
| **תפריט דיגיטלי (עורך)** | `/admin/menu` | הצוות — עריכת התפריט במסך מלא (הוספה/שינוי מנות) |
| שיתוף ופוסטר | `/admin/share` | הצוות — שליחת קישור הצטרפות בוואטסאפ + פוסטר QR |
| הגדרות | `/admin/settings` | הצוות — לוגו, הנחה, הודעות, סיסמה |
| הדפסת כרטיס חבר | `/admin/card/…` | הצוות — כרטיס עם ברקוד להדפסה (נפתח מהטבלה) |

הניווט בניהול הוא סיידבר מעוצב בדסקטופ ומגירת תפריט במובייל — מותאם לכל גודל מסך.

**סיסמת ברירת המחדל לניהול:** `micnic2026` — מומלץ להחליף מיד בעמוד ההגדרות.

## איך זה עובד ביום-יום

1. **לקוח חדש בדלפק?** העובד ממלא שם + טלפון בעמוד הניהול, לוחץ על כפתור הוואטסאפ הירוק — נפתח צ'אט עם ההודעה החמודה וההנחה מולאה מראש, ונשאר רק ללחוץ "שלח".
2. **לקוחות שמצטרפים לבד?** סורקים את ה-QR מהפוסטר בדלפק, ממלאים שני שדות בטלפון, ומקבלים את כרטיס החבר הדיגיטלי עם הברקוד האישי.
3. **מימוש הנחה בקופה?** מחפשים את הלקוח לפי טלפון/שם בעמוד הניהול (שורת החיפוש קולטת גם קורא ברקוד פיזי) — מספר החבר מופיע ואיתו ההנחה. אפשר גם להדפיס ללקוח כרטיס חבר עם הברקוד שלו (כפתור המדפסת בטבלה).
4. **רוצים לגייס חברים חדשים?** בעמוד "שיתוף ופוסטר" מזינים מספר של לקוח פוטנציאלי ושולחים לו בוואטסאפ הזמנה עם קישור ההצטרפות וההטבות — או מציבים את פוסטר ה-QR בדלפק.

## הרצה מקומית (על מחשב העסק)

```bash
npm install
npm run dev
```

פותחים את `http://localhost:3000` בדפדפן. זהו — בלי כלום חיצוני.

כל הנתונים (לקוחות + הגדרות) נשמרים אוטומטית בקובץ `data/db.json`.
הקובץ נמצא ב-gitignore כדי שפרטי הלקוחות לא יעלו ל-Git.

להרצה קבועה על מחשב הדלפק מומלץ: `npm run build` ואז `npm run start`.

## פריסה ב-Vercel (כשתהיו מוכנים)

חשוב לדעת: ב-Vercel אין מערכת קבצים קבועה, ולכן **חובה לחבר MongoDB** — אחרת רשימת הלקוחות תימחק בין ביקורים.

1. פותחים חשבון חינם ב-[MongoDB Atlas](https://www.mongodb.com/atlas) ויוצרים Cluster (התוכנית החינמית מספקת בהחלט).
2. ב-Atlas יוצרים משתמש בסיסי נתונים, מאשרים גישה מכל כתובת IP (ל-Vercel צריך `0.0.0.0/0`), ומעתיקים את מחרוזת החיבור (מתחילה ב-`mongodb+srv://`).
3. מעלים את הפרויקט ל-GitHub ומייבאים ב-[vercel.com](https://vercel.com) (Add New → Project).
4. בהגדרות הפרויקט ב-Vercel מוסיפים משתני סביבה:
   - `MONGODB_URI` — מחרוזת החיבור מ-Atlas
   - `AUTH_SECRET` — כל מחרוזת ארוכה ואקראית (לאבטחת החיבור של הצוות)
5. Deploy — והמערכת עוברת אוטומטית מקובץ JSON ל-MongoDB, בלי שום שינוי קוד.

## טכנולוגיות

- **Next.js 16** (App Router) + **TypeScript** strict
- **Tailwind CSS 4** + פונט **Rubik** (גוגל פונטס)
- **jsbarcode** — ברקוד Code128 על כרטיס החבר · **qr-code-styling** — QR מעוצב עם הלוגו
- **zod** — ולידציה · **mongodb** — כשמחברים ענן
- אחסון גמיש: `lib/db/json.ts` (מקומי) או `lib/db/mongo.ts` (ענן) מאחורי אותו ממשק

## מבנה עיקרי

```
app/            עמודים ו-API (App Router)
components/     רכיבי UI — כרטיס חבר, ברקוד, QR, כפתור וואטסאפ
lib/db/         שכבת אחסון (JSON / Mongo) מאחורי interface אחד
lib/            טלפון, וואטסאפ, אימות צוות
data/db.json    נתונים מקומיים (לא נשמר ב-Git)
```
